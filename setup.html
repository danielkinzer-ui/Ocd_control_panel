Set up OCD Control on another phone

Only run this on a phone you own. This installs the OCD daemon so that phone can be controlled (by its owner, via its own panel or paired gateway). It requires Termux to be installed and your explicit tap to run the command. There is no silent/remote install — you must open this page and run the step yourself.

Step 1 — Open this page on the phone to set up

On the other phone (the one you're adding), open this same link in its browser. The install command below is pre-filled with this server's address.

Step 2 — Install (one-tap copy)

1. Install Termux (F-Droid) on the phone.

2. Copy the command, open Termux, paste and run:

loading…

The command clones the repo, installs Node.js + Termux:API, and runs the installer. You'll see the daemon TOKEN it prints.

Step 3 — Start the daemon & open its panel

bash ~/ocd-control/start.sh        # prints a TOKEN; daemon on :18790
bash ~/ocd-control/serve-panel.sh 8080 # panel on :8080
Then open http://<this-phone-ip>:8080/panel.html on that phone (or any device on its WiFi). That phone is now controllable on its own.

Step 4 (optional) — Control it through your MacBook / gateway

To drive this phone from your existing OpenClaw gateway / MacBook chat, point the android-control plugin's daemonUrl at this phone's IP instead of 127.0.0.1:18790: 
proot-distro login ubuntu -- sh -c 'openclaw plugins configure android-control --set daemonUrl=http://<this-phone-ip>:18790 --set token=<TOKEN>'
openclawx restart
(This routes the android tool to the new phone. Repeat per phone to switch targets.)

Self-hosted onboarding. The installer is fetched from the panel server you opened this page from. No data leaves your network except the GitHub clone.
